# Sistema de registro de incidencias

Aplicación web sencilla (HTML, CSS y JavaScript) para registrar incidencias reportadas por usuarios y consultar su estado.

## Funcionalidades
- Registrar incidencias (título, descripción, prioridad).
- Listar incidencias registradas.
- Filtrar por estado y cambiar el estado (desde v1.1.0).

## Ejecutar localmente
1. Clonar: `git clone https://github.com/Diana-avila-v/incidencias-app.git`
2. Abrir `index.html` en el navegador (no requiere instalación).
3. Pruebas (requiere Node.js 20+): `node test.js`

## Versionamiento
Se usa versionamiento semántico MAJOR.MINOR.PATCH. Ver la sección *Releases* del repositorio.

## Despliegue
Al hacer push a `main`, GitHub Actions ejecuta las pruebas y publica en GitHub Pages: https://USUARIO.github.io/REPOSITORIO/
